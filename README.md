# ⚡ Remotion Cloud Studio

> 基于 **GitHub Actions 免费 CI/CD 算力** 与 **Remotion 前端代码渲染** 的全自动脱机视频生产工作台。

## ✨ 核心特性
- **零本地性能占用**：视频完全在 GitHub Actions 虚拟机（4 核 CPU / 16GB 内存）静默渲染，风扇不转，电脑不卡。
- **微软神经网络语音 (TTS)**：内置 Edge-TTS，覆盖普通话、东北方言、英文等多种高保真音色。
- **现代化可视化管理面板**：直接在网页端输入文案、选择音色、一键触发渲染、实时跟踪进度并在线播放/下载 MP4 成片。
- **永久托管与免费配额**：每月享有 2,000+ 分钟免费 Linux 运行时间。

## 🚀 网页管理面板使用方法
只需在浏览器中打开 `index.html`（或部署在 GitHub Pages），即可享受完整的可视化操作体验！
